Claude Code 導入マニュアル

撮った動画を、
Premiereで直せる形でカット編集。

Claude Code にプロンプトを1回貼るだけで、無音の間と言い直しをカットしたシーケンス・字幕・YouTubeチャプターを作る「スキル」を、自分のPCに作れます。仕上げはいつものPremiereで自由に直せます。

Premiere Pro 2020〜2026 Windows 向け（Macも可） Claude Code
01

これは何？ — カット編集の下ごしらえをAIに任せる

YouTubeの長尺動画で一番時間がかかるのは、無音の間や言い直しを1つずつ切っていく作業です。このマニュアルで作るスキルは、その下ごしらえを Claude Code が代わりにやり、Premiereで開けるカット済みのシーケンスとして渡してくれます。

カットはタイムライン上の普通のクリップなので、「ここは残したい」「ここもっと詰めたい」を、あとからいつも通りPremiereで直せます。

BEFORE

全部手作業

30分の素材を再生しながら、無音と言い直しを1つずつカット
字幕を打ち込み、チャプターの時間を手で拾う
AFTER

「この動画を編集して」と頼むだけ

カット済みシーケンス・字幕・チャプターがPremiereに入った状態からスタート
自分は確認と仕上げ（テロップ・BGM・サムネ）に集中できる

🎞 スキルがやること・やらないこと

やることやらないこと（Premiereで自分で）
文字起こし（GPUで高速）テロップのデザイン
0.45秒以上の間を0.2秒に詰めるBGM・効果音
言い直しは後のテイクを残してカットズーム・画面の動き
字幕（SRT）を作って字幕トラックにサムネイル
チャプターを作ってマーカーを打つ書き出し（エクスポート）
💡「Fable 5.1が動画を編集した」という話との違い：話題になった編集は、Premiereを使わずにプログラム（コード）で映像を作る方法でした。こちらは「あとから自分でPremiereで直したい」人向けに、Premiereで開ける形で出す方法です。
02

準備するもの

足りないものがあっても大丈夫です。導入の最初に Claude Code が確認して、入れ方を案内してくれます（入れる前に必ず確認を取ります）。

必要なもの目安
Adobe Premiere Pro2020〜2026
Claude Codeターミナル版・VS Code系エディタの拡張どちらでもOK
Node.js20.19 以上
Python3.10 以上
FFmpegコマンドで ffmpeg が動く状態
faster-whisper文字起こし用。NVIDIAのGPUがあると速い（なくても動くが遅い）
⚠️Premiereの外部操作には、無料のオープンソース premiere-pro-mcp（MITライセンス）を使います。Adobeの公式ツールではありません。導入時にPremiereへ拡張機能を入れ、署名なしの拡張機能を許可する設定（PlayerDebugMode）が変わります。
✅おすすめモデルは、そのとき一番賢いモデル（例：Claude Fable 5.1）。手順が長いので、賢いモデルほど途中で迷いにくいです。

04
短い動画で動作確認

  

    
いきなり本番の長い動画で使わず、1〜2分の短い動画で一度通します。Claude Code と一緒に、次の8つを確認します。

    

      
#確認すること

      
1文字起こしがGPUで動いた

      
2Premiereで開ける。メディアオフライン（赤い画面）が出ない

      
3カットの数が、Claude Code の報告と同じ

      
4音が左右両方から出る、映像と音がズレていない

      
5解像度・フレームレートが元の動画と同じ

      
6字幕がセリフと合っている（後半でもズレない）

      
7チャプターのマーカーが話題の頭にある

      
8元の動画ファイルが変わっていない

    

  


  
⚠️スクリプトはテスト動画で「文字起こし→カット→字幕→チャプター→確認動画」まで動作確認済みですが、Premiereへの読み込みは使う人のPC・Premiereのバージョンで差が出ることがあります。だから最初に短い動画で確認し、ズレや不具合があればその場で Claude Code に直してもらう流れにしています。

🎛 よく調整するポイント

    

      
こうしたい伝え方の例

      
間をもっと残したい「間は0.3秒くらい残して」

      
言葉の頭や語尾が切れる「言葉の前後をもう少し残して」

06
困ったとき

  
基本は、症状をそのまま Claude Code に伝えれば手順書を見て直してくれます。よくあるものだけ載せています。


  

    エクステンションのメニューに「MCP for Adobe Premiere Pro」が出ない
    

      
Premiereを完全に終了してから、Claude Code に「拡張機能の診断をして入れ直して」と伝えてください。premiere-pro-mcp --diagnose-cep で原因を調べ、入れ直してくれます。

    

  


  

    Premiereで開くと赤い画面（メディアオフライン）になる
    

      
動画ファイルの場所をPremiereが見つけられていません。フォルダ名に日本語やスペースがあると起きることがあります。Claude Code に「メディアオフラインになった」と伝えてください。すぐ試すなら、Premiereの「メディアをリンク」で元の動画を選べば直ります。

    

  


  

    片側しか音が出ない／映像と音がだんだんズレる
    

      
音声のチャンネル数か、スマホ撮影の可変フレームレートが原因のことが多いです。症状をそのまま伝えてください。ズレの場合は、元動画を残したまま固定フレームレートのコピーを作ってから編集します。

    

  


  

    MCPがどうしても動かない
    

      
MCPなしでもスキルは使えます。Claude Code が作ったファイルを、自分でPremiereに読み込むだけです。

      
    
        
  • シーケンス：ファイル ＞ 読み込み → output フォルダの .xml
    • 
        
  • 字幕：_字幕.srt をプロジェクトに読み込み → タイムラインにドラッグ
    • 
        
  • チャプター：_チャプター.txt をYouTubeの概要欄に貼る
    • 
      

    

  


  

    CapCutでも使える？
    

      
CapCutは編集データを外から作れないため、シーケンスとしては渡せません。代わりに「カット済みの動画を高画質で書き出して、字幕SRTと一緒にCapCutに読み込む」ことはできます。Claude Code に「CapCut用にカット済み動画を書き出して」と頼んでください。

    

  


  

    使わなくなったので消したい
    

      
Claude Code に「premiere-pro-mcp とこのスキルをアンインストールして」と伝えてください。拡張機能の削除・MCPの登録解除・スキルフォルダの削除を、確認を取りながら進めます。
